# aegis-waf v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个可用的 Rust 反向代理 WAF：解析并执行 ModSecurity `SecRule` 核心子集，支持请求头/请求体检测、拦截/放行、规则热重载、管理 API 和 JSONL 审计，并为后续 AI 异步研判预留接缝。

**Architecture:** Cargo workspace，两个 crate：`aegis-engine`（纯同步规则引擎，无 IO）和 `aegis-proxy`（tokio + hyper 反向代理、管理面、规则加载、审计 sink）。规则集不可变，存放于 `ArcSwap`；每个请求持有固定快照。审计事件经有界队列旁路写出，不阻塞转发。

**Tech Stack:** Rust edition 2021、tokio 1、hyper 1 + hyper-util、serde/serde_yaml/serde_json、regex、arc-swap、chrono、tracing、glob、uuid、tempfile（测试）。

**Spec:** `docs/superpowers/specs/2026-10-23-aegis-waf-design.md`

## Global Constraints

- 工作目录：`D:\rust_code\aegis-waf`；所有命令默认在此目录执行。
- Rust edition 2021；本机工具链 `rustc 1.99.0`，不使用 nightly 特性。
- 两个 crate 均启用 `#![forbid(unsafe_code)]`。
- HTTP 仅支持 HTTP/1.1；上游仅支持 `http://`；v0.1 不做响应体检测。
- 引擎错误策略默认 fail-closed；规则加载失败时保留旧规则。
- 生产代码禁止 `unwrap()` / `expect()`（测试代码可用）。

```rust
use std::path::PathBuf;

use aegis_proxy::{Config, run};

struct Cli {
    config: PathBuf,
    check: bool,
}

fn parse_cli<I>(args: I) -> Result<Cli, String>
where
    I: IntoIterator<Item = String>,
{
    let mut config = None;
    let mut check = false;
    let mut args = args.into_iter();
    while let Some(arg) = args.next() {
        match arg.as_str() {
            "--config" => {
                config = Some(PathBuf::from(
                    args.next().ok_or("--config requires a path")?,
                ));
            }
            "--check" => check = true,
            "-h" | "--help" => {
                return Err("usage: aegis-proxy --config <path> [--check]".to_string());
            }
            other if other.starts_with("--config=") => {
                config = Some(PathBuf::from(&other["--config=".len()..]));
            }
            other => return Err(format!("unknown argument: {other}")),
        }
    }
    Ok(Cli {
        config: config.ok_or("--config <path> is required")?,
        check,
    })
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    tracing_subscriber::fmt()
        .with_env_filter(tracing_subscriber::EnvFilter::from_default_env())
        .init();
    let cli = parse_cli(std::env::args().skip(1)).map_err(anyhow::Error::msg)?;
    let config = Config::load(&cli.config)?;
    let rule_files = config.validate()?;
    if cli.check {
        println!("configuration OK: {} rule file(s)", rule_files.len());
        return Ok(());
    }
    run(config).await
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn parses_config_and_check_flags() {
        let cli = parse_cli(["--config".into(), "a.yaml".into(), "--check".into()]).unwrap();
        assert_eq!(cli.config, PathBuf::from("a.yaml"));
        assert!(cli.check);
    }

    #[test]
    fn rejects_missing_config() {
        assert!(parse_cli(["--check".into()]).is_err());
    }
}
```

```rust
    UpstreamPathUnsupported(String),
    #[error("admin listener {0} is not loopback and admin.token is not set")]
    AdminTokenRequired(String),
    #[error("admin.token must not be empty")]
    EmptyAdminToken,
    #[error("rules.files must not be empty")]
    EmptyRuleFiles,
    #[error("no rule files matched pattern {0}")]
    NoRuleFiles(String),
    #[error("invalid glob pattern {pattern}: {source}")]
    InvalidGlob {
        pattern: String,
        #[source]
        source: glob::PatternError,
    },
    #[error("failed to read glob entry for {pattern}: {source}")]
    GlobEntry {
        pattern: String,
        #[source]
        source: glob::GlobError,
    },
    #[error("audit.path is required when audit.sink = file")]
    AuditPathRequired,
    #[error("{field} must be greater than zero")]
    ZeroValue { field: &'static str },
}

impl Config {
    pub fn load(path: &Path) -> Result<Self, ConfigError> {
        let text = fs::read_to_string(path).map_err(|source| ConfigError::Read {
            path: path.to_path_buf(),
            source,
        })?;
        serde_yaml::from_str(&text).map_err(|source| ConfigError::Parse {
            path: path.to_path_buf(),
            source,
        })
    }

    pub fn validate(&self) -> Result<Vec<PathBuf>, ConfigError> {
        self.listen
            .parse::<SocketAddr>()
            .map_err(|source| ConfigError::InvalidListen {
                value: self.listen.clone(),
                source,
            })?;

        let admin_addr =
            self.admin
                .listen
                .parse::<SocketAddr>()
                .map_err(|source| ConfigError::InvalidAdminListen {
                    value: self.admin.listen.clone(),
                    source,
                })?;
        match self.admin.token.as_deref() {
            Some("") => return Err(ConfigError::EmptyAdminToken),
            Some(_) => {}
            None if !admin_addr.ip().is_loopback() => {
                return Err(ConfigError::AdminTokenRequired(self.admin.listen.clone()));
            }
            None => {}
        }

        let uri: http::Uri =
            self.upstream
                .url
                .parse()
                .map_err(|source: http::uri::InvalidUri| ConfigError::InvalidUpstream {
                    value: self.upstream.url.clone(),
                    reason: source.to_string(),
                })?;
        if uri.scheme_str() != Some("http") {
            return Err(ConfigError::UpstreamScheme(self.upstream.url.clone()));
        }
        if uri.authority().is_none() {
            return Err(ConfigError::InvalidUpstream {
                value: self.upstream.url.clone(),
                reason: "missing authority".to_string(),
            });
        }
        if uri.query().is_some() {
            return Err(ConfigError::UpstreamPathUnsupported(
                self.upstream.url.clone(),
            ));
        }
        if !matches!(uri.path(), "" | "/") {
            return Err(ConfigError::UpstreamPathUnsupported(
                self.upstream.url.clone(),
            ));
        }

        if self.rules.files.is_empty() {
            return Err(ConfigError::EmptyRuleFiles);
        }
        for (field, value) in [
            ("limits.max_header_bytes", self.limits.max_header_bytes),
            ("limits.max_uri_bytes", self.limits.max_uri_bytes),
            ("limits.max_body_bytes", self.limits.max_body_bytes),
            ("limits.header_read_timeout_ms", self.limits.header_read_timeout_ms as usize),
            ("limits.body_read_timeout_ms", self.limits.body_read_timeout_ms as usize),
            ("audit.queue_capacity", self.audit.queue_capacity),
            ("audit.matched_rules_limit", self.audit.matched_rules_limit),
        ] {
            if value == 0 {
                return Err(ConfigError::ZeroValue { field });
            }
        }
        if self.audit.sink == AuditSink::File
            && self.audit.path.as_deref().unwrap_or("").is_empty()
        {
            return Err(ConfigError::AuditPathRequired);
        }

        resolve_rule_files(&self.rules.files)
    }
}

pub fn resolve_rule_files(patterns: &[String]) -> Result<Vec<PathBuf>, ConfigError> {
    if patterns.is_empty() {
        return Err(ConfigError::EmptyRuleFiles);
    }
    let mut files = Vec::new();
    let mut seen = std::collections::HashSet::new();
    for pattern in patterns {
        let entries = glob::glob(pattern).map_err(|source| ConfigError::InvalidGlob {
            pattern: pattern.clone(),
            source,
        })?;
        let mut pattern_files = Vec::new();
        for entry in entries {
            let path = entry.map_err(|source| ConfigError::GlobEntry {
                pattern: pattern.clone(),
                source,
            })?;
            if path.is_file() {
                pattern_files.push(path);
            }
        }
        if pattern_files.is_empty() {
            return Err(ConfigError::NoRuleFiles(pattern.clone()));
        }
        pattern_files.sort();
        for path in pattern_files {
            if seen.insert(path.clone()) {
                files.push(path);
            }
        }
    }
    Ok(files)
}
```

```rust
use std::time::Duration;

use bytes::{Bytes, BytesMut};
use http_body_util::BodyExt;
use hyper::body::Incoming;

#[derive(Debug)]
pub enum BodyError {
    TooLarge,
    Timeout,
    Hyper(hyper::Error),
}

pub async fn read_body_limited(
    mut body: Incoming,
    limit: usize,
    timeout: Duration,
) -> Result<Bytes, BodyError> {
    let read = async {
        let mut buffer = BytesMut::new();
        while let Some(frame) = body.frame().await {
            let frame = frame.map_err(BodyError::Hyper)?;
            if let Ok(data) = frame.into_data() {
                if buffer.len() + data.len() > limit {
                    return Err(BodyError::TooLarge);
                }
                buffer.extend_from_slice(&data);
            }
        }
        Ok(buffer.freeze())
    };
    match tokio::time::timeout(timeout, read).await {
        Ok(result) => result,
        Err(_) => Err(BodyError::Timeout),
    }
}
```

```rust
use std::net::IpAddr;
use std::str::FromStr;

use bytes::Bytes;
use http::request::Parts;
use http::{HeaderName, HeaderValue, Uri, Version};
use http_body_util::{BodyExt, Full};
use hyper::header::HOST;
use hyper::{Request, Response};

use crate::config::HostHeader;
use crate::proxy::ProxyBody;
use crate::state::AppState;

const HOP_BY_HOP: &[&str] = &[
    "connection",
    "keep-alive",
    "proxy-authenticate",
    "proxy-authorization",
    "te",
    "trailers",
    "transfer-encoding",
    "upgrade",
];

#[derive(Debug)]
pub enum ForwardError {
    Timeout,
    Upstream(String),
}

pub async fn forward(
    state: &AppState,
    parts: &Parts,
    body: Bytes,
    peer_ip: IpAddr,
) -> Result<Response<ProxyBody>, ForwardError> {
    let base: Uri = state
        .config
        .upstream
        .url
        .parse()
        .map_err(|error: http::uri::InvalidUri| ForwardError::Upstream(error.to_string()))?;
    let authority = base
        .authority()
        .ok_or_else(|| ForwardError::Upstream("upstream URL has no authority".to_string()))?
        .clone();
    let path_and_query = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str())
        .unwrap_or("/");
    let uri: Uri = format!(
        "{}://{}{}",
        base.scheme_str().unwrap_or("http"),
        authority.as_str(),
        path_and_query
    )
    .parse()
    .map_err(|error: http::uri::InvalidUri| ForwardError::Upstream(error.to_string()))?;

    let mut headers = parts.headers.clone();
    for name in HOP_BY_HOP {
        headers.remove(*name);
    }
    if state.config.upstream.host_header == HostHeader::Rewrite {
        headers.insert(
            HOST,
            HeaderValue::from_str(authority.as_str())
                .map_err(|error| ForwardError::Upstream(error.to_string()))?,
        );
    }
    let forwarded_for = match headers
        .get("x-forwarded-for")
        .and_then(|value| value.to_str().ok())
    {
        Some(existing) => format!("{existing}, {peer_ip}"),
        None => peer_ip.to_string(),
    };
    headers.insert(
        HeaderName::from_static("x-forwarded-for"),
        HeaderValue::from_str(&forwarded_for)
            .map_err(|error| ForwardError::Upstream(error.to_string()))?,
    );
    headers.insert(
        HeaderName::from_static("x-forwarded-proto"),
        HeaderValue::from_static("http"),
    );
    if let Some(host) = parts.headers.get(HOST) {
        headers.insert(HeaderName::from_static("x-forwarded-host"), host.clone());
    }

    let mut request = Request::builder()
        .method(parts.method.clone())
        .uri(uri)
        .version(Version::HTTP_11)
        .body(Full::new(body))
        .map_err(|error| ForwardError::Upstream(error.to_string()))?;
    *request.headers_mut() = headers;

    let timeout = std::time::Duration::from_millis(state.config.upstream.total_timeout_ms);
    let response = match tokio::time::timeout(timeout, state.client.request(request)).await {
        Err(_) => return Err(ForwardError::Timeout),
        Ok(Err(error)) => return Err(ForwardError::Upstream(error.to_string())),
        Ok(Ok(response)) => response,
    };

    let (mut response_parts, response_body) = response.into_parts();
    for name in HOP_BY_HOP {
        response_parts.headers.remove(*name);
    }
    let mut response = Response::builder()
        .status(response_parts.status)
        .version(Version::HTTP_11)
        .body(response_body.boxed())
        .map_err(|error| ForwardError::Upstream(error.to_string()))?;
    *response.headers_mut() = response_parts.headers;
    Ok(response)
}
```

```rust
use std::convert::Infallible;
use std::net::SocketAddr;
use std::sync::Arc;
use std::time::Duration;

use bytes::Bytes;
use http_body_util::combinators::BoxBody;
use http_body_util::{BodyExt, Full};
use hyper::body::Incoming;
use hyper::header::CONTENT_LENGTH;
use hyper::service::service_fn;
use hyper::{Request, Response, StatusCode};
use hyper_util::rt::{TokioIo, TokioTimer};
use tokio::net::TcpListener;
use tracing::{debug, warn};

use crate::state::AppState;

pub mod forward;
pub mod limits;

pub type ProxyBody = BoxBody<Bytes, hyper::Error>;

pub fn full_body(bytes: impl Into<Bytes>) -> ProxyBody {
    Full::new(bytes.into())
        .map_err(|error: std::convert::Infallible| match error {})
        .boxed()
}

pub fn text_response(status: StatusCode, message: &'static str) -> Response<ProxyBody> {
    match Response::builder()
        .status(status)
        .header("content-type", "text/plain; charset=utf-8")
        .body(full_body(message))
    {
        Ok(response) => response,
        Err(_) => {
            let mut response =
                Response::new(full_body("internal error\n"));
            *response.status_mut() = StatusCode::INTERNAL_SERVER_ERROR;
            response
        }
    }
}

fn header_bytes(headers: &hyper::HeaderMap) -> usize {
    headers
        .iter()
        .map(|(name, value)| name.as_str().len() + value.as_bytes().len() + 4)
        .sum()
}

fn content_length(headers: &hyper::HeaderMap) -> Option<u64> {
    headers
        .get(CONTENT_LENGTH)
        .and_then(|value| value.to_str().ok())
        .and_then(|value| value.parse::<u64>().ok())
}

pub async fn serve_on(listener: TcpListener, state: Arc<AppState>) -> anyhow::Result<()> {
    loop {
        let (stream, peer) = listener.accept().await?;
        let header_timeout =
            Duration::from_millis(state.config.limits.header_read_timeout_ms);
        let state = state.clone();
        tokio::spawn(async move {
            let io = TokioIo::new(stream);
            let service = service_fn(move |request| handle(request, state.clone(), peer));
            let mut builder = hyper::server::conn::http1::Builder::new();
            builder.timer(TokioTimer::new());
            builder.header_read_timeout(header_timeout);
            if let Err(error) = builder.serve_connection(io, service).await {
                debug!(%peer, %error, "connection closed");
            }
        });
    }
}

async fn handle(
    request: Request<Incoming>,
    state: Arc<AppState>,
    peer: SocketAddr,
) -> Result<Response<ProxyBody>, Infallible> {
    let (parts, incoming) = request.into_parts();

    let uri_len = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str().len())
        .unwrap_or(0);
    if uri_len > state.config.limits.max_uri_bytes {
        return Ok(text_response(StatusCode::URI_TOO_LONG, "URI too long\n"));
    }
    if header_bytes(&parts.headers) > state.config.limits.max_header_bytes {
        return Ok(text_response(
            StatusCode::REQUEST_HEADER_FIELDS_TOO_LARGE,
            "request headers too large\n",
        ));
    }
    if let Some(length) = content_length(&parts.headers) {
        if length > state.config.limits.max_body_bytes as u64 {
            return Ok(text_response(
                StatusCode::PAYLOAD_TOO_LARGE,
                "request body too large\n",
            ));
        }
    }

    let body = match limits::read_body_limited(
        incoming,
        state.config.limits.max_body_bytes,
        Duration::from_millis(state.config.limits.body_read_timeout_ms),
    )
    .await
    {
        Ok(body) => body,
        Err(limits::BodyError::TooLarge) => {
            return Ok(text_response(
                StatusCode::PAYLOAD_TOO_LARGE,
                "request body too large\n",
            ));
        }
        Err(limits::BodyError::Timeout) => {
            return Ok(text_response(
                StatusCode::REQUEST_TIMEOUT,
                "request body read timeout\n",
            ));
        }
        Err(limits::BodyError::Hyper(error)) => {
            warn!(%peer, %error, "failed to read request body");
            return Ok(text_response(
                StatusCode::BAD_REQUEST,
                "invalid request body\n",
            ));
        }
    };

    match forward::forward(&state, &parts, body, peer.ip()).await {
        Ok(response) => Ok(response),
        Err(forward::ForwardError::Timeout) => Ok(text_response(
            StatusCode::GATEWAY_TIMEOUT,
            "upstream timeout\n",
        )),
        Err(forward::ForwardError::Upstream(error)) => {
            warn!(%peer, %error, "upstream request failed");
            Ok(text_response(StatusCode::BAD_GATEWAY, "upstream error\n"))
        }
    }
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LogicalLine {
    pub text: String,
    pub line: usize,
}

pub fn split_logical_lines(input: &str) -> Vec<LogicalLine> {
    let mut result = Vec::new();
    let mut current = String::new();
    let mut start_line = 0usize;
    let mut in_single = false;
    let mut in_double = false;

    for (index, raw) in input.lines().enumerate() {
        let line_number = index + 1;
        let line = strip_comment(raw, &mut in_single, &mut in_double);
        let trimmed_end = line.trim_end();
        let continuation = ends_with_unescaped_backslash(trimmed_end);
        let segment = if continuation {
            &trimmed_end[..trimmed_end.len() - 1]
        } else {
            trimmed_end
        };
        if current.is_empty() {
            start_line = line_number;
        } else {
            current.push(' ');
        }
        current.push_str(segment.trim_start());
        if !continuation {
            let text = current.trim().to_string();
            if !text.is_empty() {
                result.push(LogicalLine {
                    text,
                    line: start_line,
                });
            }
            current.clear();
            start_line = 0;
        }
    }

    let text = current.trim().to_string();
    if !text.is_empty() {
        result.push(LogicalLine {
            text,
            line: start_line,
        });
    }
    result
}

fn strip_comment<'a>(line: &'a str, in_single: &mut bool, in_double: &mut bool) -> &'a str {
    let bytes = line.as_bytes();
    let mut index = 0;
    while index < bytes.len() {
        let byte = bytes[index];
        if *in_single {
            if byte == b'\\' {
                index += 2;
                continue;
            }
            if byte == b'\'' {
                *in_single = false;
            }
        } else if *in_double {
            if byte == b'\\' {
                index += 2;
                continue;
            }
            if byte == b'"' {
                *in_double = false;
            }
        } else if byte == b'\'' {
            *in_single = true;
        } else if byte == b'"' {
            *in_double = true;
        } else if byte == b'#' {
            return &line[..index];
        }
        index += 1;
    }
    line
}

fn ends_with_unescaped_backslash(text: &str) -> bool {
    let count = text
        .as_bytes()
        .iter()
        .rev()
        .take_while(|byte| **byte == b'\\')
        .count();
    count % 2 == 1
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RawArg {
    pub value: String,
    pub column: usize,
}

pub fn split_args(input: &str) -> Result<Vec<RawArg>, String> {
    let mut args = Vec::new();
    let mut chars = input.char_indices().peekable();

    while let Some(&(start, first)) = chars.peek() {
        if first.is_whitespace() {
            chars.next();
            continue;
        }
        let mut value = String::new();
        let mut quote: Option<char> = None;
        while let Some(&(_, ch)) = chars.peek() {
            if let Some(delimiter) = quote {
                chars.next();
                if ch == '\\' {
                    match chars.peek() {
                        Some(&(_, escaped)) if escaped == delimiter || escaped == '\\' => {
                            value.push(escaped);
                            chars.next();
                        }
                        _ => value.push('\\'),
                    }
                } else if ch == delimiter {
                    quote = None;
                } else {
                    value.push(ch);
                }
            } else if ch == '"' || ch == '\'' {
                quote = Some(ch);
                chars.next();
            } else if ch.is_whitespace() {
                break;
            } else {
                value.push(ch);
                chars.next();
            }
        }
        if quote.is_some() {
            return Err(format!("unterminated quote at column {}", start + 1));
        }
        args.push(RawArg {
            value,
            column: start + 1,
        });
    }
    Ok(args)
}
```

```rust
pub fn parse_directive(line: &LogicalLine) -> Result<Directive, ParseError> {
    let text = line.text.trim();
    let name_end = text.find(char::is_whitespace).unwrap_or(text.len());
    let name = &text[..name_end];
    let rest = text[name_end..].trim();

        line: line.line,
        column,
        message,
    };

    match lower_name.as_str() {
        "secrule" => {
            let args = split_args(rest).map_err(|message| fail(1, message))?;
            if args.len() != 3 {
                return Err(fail(
                    args.first().map(|arg| arg.column).unwrap_or(1),
                    format!("SecRule expects 3 arguments, got {}", args.len()),
                ));
            }
            Ok(Directive::Rule(RuleAst {
                variables: args[0].value.clone(),
                operator: args[1].value.clone(),
                actions: args[2].value.clone(),
                line: line.line,
                column: args[0].column,
            }))
        }
        "secaction" | "secdefaultaction" => {
            let args = split_args(rest).map_err(|message| fail(1, message))?;
            if args.len() != 1 {
                return Err(fail(
                    args.first().map(|arg| arg.column).unwrap_or(1),
                    format!("{name} expects 1 argument, got {}", args.len()),
                ));
            }
            let actions = args[0].value.clone();
            let column = args[0].column;
            if name.eq_ignore_ascii_case("secaction") {
                Ok(Directive::Action(ActionAst {
                    actions,
                    line: line.line,
                    column,
                }))
            } else {
                Ok(Directive::DefaultAction(DefaultActionAst {
                    actions,
                    line: line.line,
                    column,
                }))
            }
        }
        "secmarker" | "include" => {

                    args.first().map(|arg| arg.column).unwrap_or(1),

            }
```

```rust
pub mod args;
pub mod directive;
pub mod scanner;

use std::collections::HashSet;
use std::path::{Path, PathBuf};

use crate::error::LoadError;

pub use directive::Directive;

pub const MAX_INCLUDE_DEPTH: usize = 8;

#[derive(Debug, Clone)]
pub struct LocatedDirective {
    pub file: PathBuf,
    pub directive: Directive,
}

pub fn parse_files(files: &[PathBuf]) -> Result<Vec<LocatedDirective>, LoadError> {
    let mut output = Vec::new();
    for file in files {
        let mut visited = HashSet::new();
        parse_one(file, 0, &mut visited, &mut output)?;
    }
    Ok(output)
}

fn parse_one(
    path: &Path,
    depth: usize,
    visited: &mut HashSet<PathBuf>,
    output: &mut Vec<LocatedDirective>,
) -> Result<(), LoadError> {
    if depth > MAX_INCLUDE_DEPTH {
        return Err(LoadError::IncludeDepth(path.to_path_buf()));
    }
    let identity = path.canonicalize().unwrap_or_else(|_| path.to_path_buf());
    if !visited.insert(identity) {
        return Err(LoadError::IncludeCycle(path.to_path_buf()));
    }

    let text = std::fs::read_to_string(path).map_err(|source| LoadError::Io {
        file: path.to_path_buf(),
        source,
    })?;

    for logical in scanner::split_logical_lines(&text) {
        match directive::parse_directive(&logical) {
            Ok(Directive::Include(pattern)) => {
                let base = path.parent().unwrap_or_else(|| Path::new("."));
                let pattern_path = base.join(&pattern);
                let pattern_text = pattern_path.to_string_lossy().replace('\\', "/");
                let entries = glob::glob(&pattern_text).map_err(|error| LoadError::IncludeGlob {
                    file: path.to_path_buf(),
                    line: logical.line,
                    message: error.to_string(),
                })?;
                let mut included = Vec::new();
                for entry in entries {
                    let entry = entry.map_err(|error| LoadError::IncludeGlob {
                        file: path.to_path_buf(),
                        line: logical.line,
                        message: error.to_string(),
                    })?;
                    if entry.is_file() {
                        included.push(entry);
                    }
                }
                if included.is_empty() {
                    return Err(LoadError::IncludeNoMatch {
                        file: path.to_path_buf(),
                        line: logical.line,
                        pattern,
                    });
                }
                included.sort();
                for entry in included {
                    parse_one(&entry, depth + 1, visited, output)?;
                }
            }
            Ok(directive) => output.push(LocatedDirective {
                file: path.to_path_buf(),
                directive,
            }),
            Err(error) => {
                return Err(LoadError::Parse {
                    file: path.to_path_buf(),
                    line: error.line,
                    column: error.column,
                    message: error.message,
                });
            }
        }
    }
    Ok(())
}
```

```rust
use std::net::IpAddr;

use ipnet::IpNet;

#[derive(Debug, Clone)]
pub enum CompiledOperator {
    Rx(regex::Regex),
    Eq(String),
    Contains(String),
    BeginsWith(String),
    EndsWith(String),
    Pm(Vec<String>),
    IpMatch(Vec<IpNet>),
    Within(String),
    Gt(i64),
    Ge(i64),
    Lt(i64),
    Le(i64),
}

impl CompiledOperator {
    pub fn matches(&self, input: &str) -> bool {
        match self {
            Self::Rx(regex) => regex.is_match(input),
            Self::Eq(expected) => input == expected,
            Self::Contains(needle) => input.contains(needle),
            Self::BeginsWith(prefix) => input.starts_with(prefix),
            Self::EndsWith(suffix) => input.ends_with(suffix),
            Self::Pm(phrases) => phrases.iter().any(|phrase| input.contains(phrase)),
            Self::IpMatch(networks) => input
                .parse::<IpAddr>()
                .map(|address| networks.iter().any(|network| network.contains(&address)))
                .unwrap_or(false),
            Self::Within(haystack) => haystack.contains(input),
            Self::Gt(value) => parse_number(input).map(|number| number > *value).unwrap_or(false),
            Self::Ge(value) => parse_number(input).map(|number| number >= *value).unwrap_or(false),
            Self::Lt(value) => parse_number(input).map(|number| number < *value).unwrap_or(false),
            Self::Le(value) => parse_number(input).map(|number| number <= *value).unwrap_or(false),
        }
    }
}

fn parse_number(input: &str) -> Option<i64> {
    input.trim().parse::<i64>().ok()
}

pub fn parse_ip_match(argument: &str) -> Result<Vec<IpNet>, String> {
    argument
        .split(',')
        .map(|item| {
            let item = item.trim();
            if let Ok(network) = item.parse::<IpNet>() {
                Ok(network)
            } else if let Ok(address) = item.parse::<IpAddr>() {
                let prefix = if address.is_ipv4() { 32 } else { 128 };
                Ok(IpNet::new(address, prefix).map_err(|error| error.to_string())?)
            } else {
                Err(format!("invalid IP or CIDR: {item}"))
            }
        })
        .collect()
}
```

```rust
use std::borrow::Cow;

use base64::Engine as _;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Transform {
    Lowercase,
    UrlDecode,
    UrlDecodeUni,
    HtmlEntityDecode,
    Trim,
    TrimLeft,
    TrimRight,
    CompressWhitespace,
    RemoveNulls,
    NormalizePath,
    Base64Decode,
}

impl Transform {
    pub fn from_name(name: &str) -> Option<Self> {
        match name.to_ascii_lowercase().as_str() {
            "lowercase" => Some(Self::Lowercase),
            "urldecode" => Some(Self::UrlDecode),
            "urldecodeuni" => Some(Self::UrlDecodeUni),
            "htmlentitydecode" => Some(Self::HtmlEntityDecode),
            "trim" => Some(Self::Trim),
            "trimleft" => Some(Self::TrimLeft),
            "trimright" => Some(Self::TrimRight),
            "compresswhitespace" => Some(Self::CompressWhitespace),
            "removenulls" => Some(Self::RemoveNulls),
            "normalizepath" => Some(Self::NormalizePath),
            "base64decode" => Some(Self::Base64Decode),
            _ => None,
        }
    }

    pub fn apply<'a>(&self, input: &'a str) -> Cow<'a, str> {
        match self {
            Self::Lowercase => {
                if input.bytes().any(|byte| byte.is_ascii_uppercase()) {
                    Cow::Owned(input.to_ascii_lowercase())
                } else {
                    Cow::Borrowed(input)
                }
            }
            Self::UrlDecode => url_decode(input, false),
            Self::UrlDecodeUni => url_decode(input, true),
            Self::HtmlEntityDecode => html_escape::decode_html_entities(input),
            Self::Trim => {
                let value = input.trim_matches(|ch: char| ch.is_ascii_whitespace());
                borrowed_if_unchanged(input, value)
            }
            Self::TrimLeft => {
                let value = input.trim_start_matches(|ch: char| ch.is_ascii_whitespace());
                borrowed_if_unchanged(input, value)
            }
            Self::TrimRight => {
                let value = input.trim_end_matches(|ch: char| ch.is_ascii_whitespace());
                borrowed_if_unchanged(input, value)
            }
            Self::CompressWhitespace => compress_whitespace(input),
            Self::RemoveNulls => {
                if input.contains('\0') {
                    Cow::Owned(input.chars().filter(|ch| *ch != '\0').collect())
                } else {
                    Cow::Borrowed(input)
                }
            }
            Self::NormalizePath => normalize_path(input),
            Self::Base64Decode => {
                match base64::engine::general_purpose::STANDARD.decode(input.as_bytes()) {
                    Ok(bytes) => Cow::Owned(String::from_utf8_lossy(&bytes).into_owned()),
                    Err(_) => Cow::Borrowed(input),
                }
            }
        }
    }
}

fn borrowed_if_unchanged<'a>(original: &'a str, value: &'a str) -> Cow<'a, str> {
    if original.len() == value.len() && original.as_ptr() == value.as_ptr() {
        Cow::Borrowed(original)
    } else {
        Cow::Borrowed(value)
    }
}

fn compress_whitespace(input: &str) -> Cow<'_, str> {
    let mut output = String::with_capacity(input.len());
    let mut previous_space = false;
    let mut changed = false;
    for ch in input.chars() {
        if ch.is_ascii_whitespace() {
            if !previous_space {
                output.push(' ');
                previous_space = true;
            } else {
                changed = true;
            }
        } else {
            output.push(ch);
            previous_space = false;
        }
    }
    if changed || output != input {
        Cow::Owned(output)
    } else {
        Cow::Borrowed(input)
    }
}

fn url_decode(input: &str, uni: bool) -> Cow<'_, str> {
    if !input.contains('%') && !input.contains('+') {
        return Cow::Borrowed(input);
    }
    let bytes = input.as_bytes();
    let mut output = Vec::with_capacity(bytes.len());
    let mut index = 0;
    while index < bytes.len() {
        match bytes[index] {
            b'+' => {
                output.push(b' ');
                index += 1;
            }
            b'%' if index + 2 < bytes.len() => {
                if uni && bytes[index + 1] == b'u' && index + 6 <= bytes.len() {
                    let code = match (
                        hex_nibble(bytes[index + 2]),
                        hex_nibble(bytes[index + 3]),
                        hex_nibble(bytes[index + 4]),
                        hex_nibble(bytes[index + 5]),
                    ) {
                        (Some(a), Some(b), Some(c), Some(d)) => {
                            Some(
                                ((a as u32) << 12)
                                    | ((b as u32) << 8)
                                    | ((c as u32) << 4)
                                    | (d as u32),
                            )
                        }
                        _ => None,
                    };
                    if let Some(ch) = code.and_then(char::from_u32) {
                        let mut buffer = [0u8; 4];
                        output.extend_from_slice(ch.encode_utf8(&mut buffer).as_bytes());
                        index += 6;
                    } else {
                        output.push(b'%');
                        index += 1;
                    }
                } else if let (Some(high), Some(low)) =
                    (hex_nibble(bytes[index + 1]), hex_nibble(bytes[index + 2]))
                {
                    output.push(high * 16 + low);
                    index += 3;
                } else {
                    output.push(b'%');
                    index += 1;
                }
            }
            byte => {
                output.push(byte);
                index += 1;
            }
        }
    }
    Cow::Owned(String::from_utf8_lossy(&output).into_owned())
}

fn hex_nibble(byte: u8) -> Option<u8> {
    match byte {
        b'0'..=b'9' => Some(byte - b'0'),
        b'a'..=b'f' => Some(byte - b'a' + 10),
        b'A'..=b'F' => Some(byte - b'A' + 10),
        _ => None,
    }
}

fn normalize_path(input: &str) -> Cow<'_, str> {
    if !input.contains('\\') && !input.contains("//") && !input.contains("/./") && !input.contains("/../")
        && !input.ends_with("/.") && !input.ends_with("/..")
    {
        return Cow::Borrowed(input);
    }
    let absolute = input.starts_with('/') || input.starts_with('\\');
    let mut segments: Vec<&str> = Vec::new();
    for segment in input.split(['/', '\\']) {
        match segment {
            "" | "." => {}
            ".." => {
                segments.pop();
            }
            value => segments.push(value),
        }
    }
    let mut output = String::new();
    if absolute {
        output.push('/');
    }
    output.push_str(&segments.join("/"));
    if output.is_empty() {
        output.push('/');
    }
    Cow::Owned(output)
}
```

```rust
pub fn load_rules(files: &[PathBuf], options: &LoadOptions) -> Result<CompiledRules, LoadError> {
    let directives = crate::parser::parse_files(files)?;
    compile_directives(directives, files.to_vec(), options)
}

fn compile_error(file: &Path, line: usize, column: usize, message: String) -> LoadError {
    LoadError::Compile {
        file: file.to_path_buf(),
        line,
        column,
        message,
    }
}

fn compile_directives(
    directives: Vec<LocatedDirective>,
    files: Vec<PathBuf>,
    options: &LoadOptions,
) -> Result<CompiledRules, LoadError> {
    let mut defaults: HashMap<PathBuf, DefaultActions> = HashMap::new();
    let mut ids = HashSet::new();
    let mut phase1 = Vec::new();
    let mut phase2 = Vec::new();
    let mut chain: Vec<CompiledRule> = Vec::new();
    let mut chain_phase: Option<Phase> = None;
    let mut last_location: Option<(PathBuf, usize, usize)> = None;
    let mut rule_count = 0usize;

    for located in directives {
        let file = located.file;
        match located.directive {
            Directive::Rule(ast) => {
                let default = defaults.get(&file).cloned().unwrap_or_default();
                let Some(rule) = compile_rule(&file, &ast, &default, options)? else {
                    continue;
                };
                if !ids.insert(rule.id) {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        format!("duplicate rule id {}", rule.id),
                    ));
                }
                rule_count += 1;
                last_location = Some((file.clone(), ast.line, ast.column));

                if rule.actions.chain && rule.actions.disruptive.is_some() {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        "chain middle rules cannot contain disruptive actions".to_string(),
                    ));
                }
                if !chain.is_empty() && chain_phase != Some(rule.phase) {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        "chain rules must share the same phase".to_string(),
                    ));
                }
                if rule.actions.chain {
                    if chain.is_empty() {
                        chain_phase = Some(rule.phase);
                    }
                    chain.push(rule);
                    continue;
                }
                if !chain.is_empty() {
                    chain.push(rule);
                    let group = RuleGroup::Chain(std::mem::take(&mut chain));
                    match chain_phase.take().unwrap_or(Phase::Phase2) {
                        Phase::Phase1 => phase1.push(group),
                        Phase::Phase2 => phase2.push(group),
                    }
                    continue;
                }
                match rule.phase {
                    Phase::Phase1 => phase1.push(RuleGroup::Single(Box::new(rule))),
                    Phase::Phase2 => phase2.push(RuleGroup::Single(Box::new(rule))),
                }
            }
            Directive::Action(ast) => {
                if !chain.is_empty() {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        "SecAction cannot appear inside a chain".to_string(),
                    ));
                }
                let Some(rule) = compile_action(&file, &ast, options)? else {
                    continue;
                };
                if !ids.insert(rule.id) {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        format!("duplicate rule id {}", rule.id),
                    ));
                }
                rule_count += 1;
                match rule.phase {
                    Phase::Phase1 => phase1.push(RuleGroup::Single(Box::new(rule))),
                    Phase::Phase2 => phase2.push(RuleGroup::Single(Box::new(rule))),
                }
            }
            Directive::DefaultAction(ast) => {
                if !chain.is_empty() {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        "SecDefaultAction cannot appear inside a chain".to_string(),
                    ));
                }
                let Some(parsed) = parse_actions(&file, ast.line, ast.column, &ast.actions, options)?
                else {
                    continue;
                };
                if parsed.id.is_some()
                    || parsed.msg.is_some()
                    || !parsed.tags.is_empty()
                    || !parsed.setvars.is_empty()
                    || parsed.logdata.is_some()
                    || parsed.chain
                {
                    return Err(compile_error(
                        &file,
                        ast.line,
                        ast.column,
                        "SecDefaultAction supports only phase, disruptive action, status, log/nolog, and t"
                            .to_string(),
                    ));
                }
                defaults.insert(file, parsed.into_default_actions());
            }
            Directive::Marker(_) => {}
            Directive::Unknown {
                name,
                line,
                column,
            } => {
                if options.lenient {
                    tracing::warn!(file = %file.display(), line, "ignoring unsupported directive {name}");
                } else {
                    return Err(compile_error(
                        &file,
                        line,
                        column,
                        format!("unsupported directive {name}"),
                    ));
                }
            }
            Directive::Include(_) => {
                return Err(compile_error(
                    &file,
                    1,
                    1,
                    "internal error: Include must be expanded by the parser".to_string(),
                ));
            }
        }
    }

    if let Some(rule) = chain.first() {
        let (file, line, column) = last_location
            .unwrap_or_else(|| (rule.file.clone(), rule.line, 1));
        return Err(compile_error(
            &file,
            line,
            column,
            "chain action on final rule (no following rule)".to_string(),
        ));
    }

    Ok(CompiledRules {
        version: options.version,
        rule_count,
        files,
        phase1,
        phase2,
    })
}

fn compile_rule(
    file: &Path,
    ast: &RuleAst,
    defaults: &DefaultActions,
    options: &LoadOptions,
) -> Result<Option<CompiledRule>, LoadError> {
    let Some(variables) = parse_variables(file, ast.line, ast.column, &ast.variables, options)? else {
        return Ok(None);
    };
    let (operator, operator_negated) =
        match parse_operator(&ast.operator) {
            Ok(value) => value,
            Err(message) => {
                if options.lenient {
                    tracing::warn!(file = %file.display(), line = ast.line, "skipping rule: {message}");
                    return Ok(None);
                }
                return Err(compile_error(file, ast.line, ast.column, message));
            }
        };
    let Some(parsed) = parse_actions(file, ast.line, ast.column, &ast.actions, options)? else {
        return Ok(None);
    };
    let Some(id) = parsed.id else {
        if options.lenient {
            tracing::warn!(file = %file.display(), line = ast.line, "skipping rule without id");
            return Ok(None);
        }
        return Err(compile_error(
            file,
            ast.line,
            ast.column,
            "rule id is required".to_string(),
        ));
    };
    let phase = match parsed.phase.or(defaults.phase) {
        Some(Phase::Phase1) => Phase::Phase1,
        Some(Phase::Phase2) => Phase::Phase2,
        None => Phase::Phase2,
    };
    let disruptive = parsed
        .disruptive
        .clone()
        .or_else(|| defaults.disruptive.clone());
    let status = parsed.status.or(defaults.status).unwrap_or(403);
    let disruptive = disruptive.map(|action| match action {
        Disruptive::Deny { .. } => Disruptive::Deny { status },
        Disruptive::Allow => Disruptive::Allow,
    });
    let log = parsed.log.or(defaults.log).unwrap_or(false);
    let mut transformations = defaults.transforms.clone();
    transformations.extend(parsed.transforms);

    Ok(Some(CompiledRule {
        id,
        phase,
        variables,
        operator,
        operator_negated,
        transformations,
        actions: CompiledActions {
            disruptive,
            log,
            msg: parsed.msg,
            severity: parsed.severity,
            tags: parsed.tags,
            setvars: parsed.setvars,
            logdata: parsed.logdata,
            chain: parsed.chain,
        },
        unconditional: false,
        file: file.to_path_buf(),
        line: ast.line,
    }))
}

fn compile_action(
    file: &Path,
    ast: &ActionAst,
    options: &LoadOptions,
) -> Result<Option<CompiledRule>, LoadError> {
    let Some(parsed) = parse_actions(file, ast.line, ast.column, &ast.actions, options)? else {
        return Ok(None);
    };
    let Some(id) = parsed.id else {
        if options.lenient {
            tracing::warn!(file = %file.display(), line = ast.line, "skipping SecAction without id");
            return Ok(None);
        }
        return Err(compile_error(
            file,
            ast.line,
            ast.column,
            "SecAction id is required".to_string(),
        ));
    };
    if parsed.chain {
        return Err(compile_error(
            file,
            ast.line,
            ast.column,
            "SecAction cannot use chain".to_string(),
        ));
    }
    let phase = parsed.phase.unwrap_or(Phase::Phase2);
    let status = parsed.status.unwrap_or(403);
    let disruptive = parsed.disruptive.map(|action| match action {
        Disruptive::Deny { .. } => Disruptive::Deny { status },
        Disruptive::Allow => Disruptive::Allow,
    });
    Ok(Some(CompiledRule {
        id,
        phase,
        variables: Vec::new(),
        operator: CompiledOperator::Eq(String::new()),
        operator_negated: false,
        transformations: Vec::new(),
        actions: CompiledActions {
            disruptive,
            log: parsed.log.unwrap_or(false),
            msg: parsed.msg,
            severity: parsed.severity,
            tags: parsed.tags,
            setvars: parsed.setvars,
            logdata: parsed.logdata,
            chain: false,
        },
        unconditional: true,
        file: file.to_path_buf(),
        line: ast.line,
    }))
}

fn parse_variables(
    file: &Path,
    line: usize,
    column: usize,
    raw: &str,
    options: &LoadOptions,
) -> Result<Option<Vec<VariableSpec>>, LoadError> {
    let mut specs = Vec::new();
    for item in raw.split('|') {
        let item = item.trim();
        if item.is_empty() {
            return Err(compile_error(file, line, column, "empty variable".to_string()));
        }
        let (negated, item) = match item.strip_prefix('!') {
            Some(rest) => (true, rest),
            None => (false, item),
        };
        if item.starts_with('&') {
            if options.lenient {
                tracing::warn!(file = %file.display(), line, "skipping rule: variable counts are unsupported");
                return Ok(None);
            }
            return Err(compile_error(
                file,
                line,
                column,
                "variable counts (&VAR) are not supported".to_string(),
            ));
        }
        let (name, selector) = match item.split_once(':') {
            Some((name, selector)) => (name, Some(selector.to_string())),
            None => (item, None),
        };
        let variable = match name.to_ascii_uppercase().as_str() {
            "REQUEST_URI" if selector.is_none() => Variable::RequestUri,
            "REQUEST_METHOD" if selector.is_none() => Variable::RequestMethod,
            "QUERY_STRING" if selector.is_none() => Variable::QueryString,
            "REQUEST_FILENAME" if selector.is_none() => Variable::RequestFilename,
            "REQUEST_HEADERS" => Variable::RequestHeaders(selector),
            "ARGS" if selector.is_none() => Variable::Args,
            "ARGS_GET" if selector.is_none() => Variable::ArgsGet,
            "ARGS_POST" if selector.is_none() => Variable::ArgsPost,
            "ARGS_NAMES" if selector.is_none() => Variable::ArgsNames,
            "REQUEST_COOKIES" => Variable::RequestCookies(selector),
            "REQUEST_BODY" if selector.is_none() => Variable::RequestBody,
            "REMOTE_ADDR" if selector.is_none() => Variable::RemoteAddr,
            "TX" => Variable::Tx(selector.map(|value| value.to_ascii_lowercase())),
            _ => {
                if options.lenient {
                    tracing::warn!(file = %file.display(), line, "skipping rule: unsupported variable {item}");
                    return Ok(None);
                }
                return Err(compile_error(
                    file,
                    line,
                    column,
                    format!("unsupported variable {item}"),
                ));
            }
        };
        specs.push(VariableSpec { variable, negated });
    }
    Ok(Some(specs))
}

fn parse_operator(raw: &str) -> Result<(CompiledOperator, bool), String> {
    let (negated, rest) = match raw.strip_prefix('!') {
        Some(rest) => (true, rest),
        None => (false, raw),
    };
    let rest = rest.trim();
    if rest.is_empty() {
        return Err("empty operator".to_string());
    }
    let (name, argument) = if let Some(after_at) = rest.strip_prefix('@') {
        match after_at.find(char::is_whitespace) {
            Some(index) => (
                after_at[..index].to_ascii_lowercase(),
                unquote(after_at[index..].trim()),
            ),
            None => (after_at.to_ascii_lowercase(), String::new()),
        }
    } else {
        ("rx".to_string(), rest.to_string())
    };
    let operator = match name.as_str() {
        "rx" => CompiledOperator::Rx(
            regex::Regex::new(&argument).map_err(|error| format!("invalid regex: {error}"))?,
        ),
        "eq" => CompiledOperator::Eq(argument),
        "contains" => CompiledOperator::Contains(argument),
        "beginswith" => CompiledOperator::BeginsWith(argument),
        "endswith" => CompiledOperator::EndsWith(argument),
        "pm" => CompiledOperator::Pm(
            argument
                .split_ascii_whitespace()
                .map(|value| value.to_string())
                .collect(),
        ),
        "ipmatch" => CompiledOperator::IpMatch(parse_ip_match(&argument)?),
        "within" => CompiledOperator::Within(argument),
        "gt" => CompiledOperator::Gt(parse_integer(&argument)?),
        "ge" => CompiledOperator::Ge(parse_integer(&argument)?),
        "lt" => CompiledOperator::Lt(parse_integer(&argument)?),
        "le" => CompiledOperator::Le(parse_integer(&argument)?),
        other => return Err(format!("unsupported operator @{other}")),
    };
    Ok((operator, negated))
}

fn parse_integer(raw: &str) -> Result<i64, String> {
    raw.trim()
        .parse::<i64>()
        .map_err(|error| format!("invalid integer {raw}: {error}"))
}

fn parse_actions(
    file: &Path,
    line: usize,
    column: usize,
    raw: &str,
    options: &LoadOptions,
) -> Result<Option<ParsedActions>, LoadError> {
    let mut parsed = ParsedActions::default();
    let mut disruptive_seen = false;
    for item in split_actions(raw) {
        let item = item.trim();
        if item.is_empty() {
            continue;
        }
        let (key, value) = match item.split_once(':') {
            Some((key, value)) => (key.trim().to_ascii_lowercase(), Some(value.trim())),
            None => (item.to_ascii_lowercase(), None),
        };
        match key.as_str() {
            "id" => {
                let raw_id = value.ok_or_else(|| {
                    compile_error(file, line, column, "id requires a value".to_string())
                })?;
                parsed.id = Some(raw_id.parse::<u32>().map_err(|error| {
                    compile_error(file, line, column, format!("invalid rule id: {error}"))
                })?);
            }
            "phase" => {
                let raw_phase = value.ok_or_else(|| {
                    compile_error(file, line, column, "phase requires a value".to_string())
                })?;
                let phase = match raw_phase {
                    "1" => Phase::Phase1,
                    "2" => Phase::Phase2,
                    "3" | "4" | "5" => {
                        if options.lenient {
                            tracing::warn!(file = %file.display(), line, "skipping rule: phase {raw_phase} is unsupported");
                            return Ok(None);
                        }
                        return Err(compile_error(
                            file,
                            line,
                            column,
                            format!("phase {raw_phase} is not supported"),
                        ));
                    }
                    other => {
                        return Err(compile_error(
                            file,
                            line,
                            column,
                            format!("invalid phase {other}"),
                        ));
                    }
                };
                parsed.phase = Some(phase);
            }
            "deny" | "block" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        format!("{key} does not accept a value"),
                    ));
                }
                if disruptive_seen {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "multiple disruptive actions".to_string(),
                    ));
                }
                disruptive_seen = true;
                parsed.disruptive = Some(Disruptive::Deny { status: 403 });
            }
            "pass" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "pass does not accept a value".to_string(),
                    ));
                }
                if disruptive_seen {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "multiple disruptive actions".to_string(),
                    ));
                }
                disruptive_seen = true;
            }
            "allow" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "allow does not accept a value".to_string(),
                    ));
                }
                if disruptive_seen {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "multiple disruptive actions".to_string(),
                    ));
                }
                disruptive_seen = true;
                parsed.disruptive = Some(Disruptive::Allow);
            }
            "status" => {
                let raw_status = value.ok_or_else(|| {
                    compile_error(file, line, column, "status requires a value".to_string())
                })?;
                let status = raw_status.parse::<u16>().map_err(|error| {
                    compile_error(file, line, column, format!("invalid status: {error}"))
                })?;
                if !(100..=599).contains(&status) {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        format!("status {status} is outside 100..=599"),
                    ));
                }
                parsed.status = Some(status);
            }
            "log" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "log does not accept a value".to_string(),
                    ));
                }
                parsed.log = Some(true);
            }
            "nolog" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "nolog does not accept a value".to_string(),
                    ));
                }
                parsed.log = Some(false);
            }
            "msg" => {
                parsed.msg = Some(unquote(value.ok_or_else(|| {
                    compile_error(file, line, column, "msg requires a value".to_string())
                })?));
            }
            "severity" => {
                parsed.severity = Some(unquote(value.ok_or_else(|| {
                    compile_error(file, line, column, "severity requires a value".to_string())
                })?));
            }
            "tag" => {
                parsed.tags.push(unquote(value.ok_or_else(|| {
                    compile_error(file, line, column, "tag requires a value".to_string())
                })?));
            }
            "rev" | "ver" => {
                let _ = value.ok_or_else(|| {
                    compile_error(file, line, column, format!("{key} requires a value"))
                })?;
            }
            "logdata" => {
                parsed.logdata = Some(unquote(value.ok_or_else(|| {
                    compile_error(file, line, column, "logdata requires a value".to_string())
                })?));
            }
            "t" => {
                let raw_transform = value.ok_or_else(|| {
                    compile_error(file, line, column, "t requires a value".to_string())
                })?;
                match Transform::from_name(raw_transform) {
                    Some(transform) => parsed.transforms.push(transform),
                    None => {
                        if options.lenient {
                            tracing::warn!(file = %file.display(), line, "ignoring unsupported transform {raw_transform}");
                        } else {
                            return Err(compile_error(
                                file,
                                line,
                                column,
                                format!("unsupported transform {raw_transform}"),
                            ));
                        }
                    }
                }
            }
            "chain" => {
                if value.is_some() {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        "chain does not accept a value".to_string(),
                    ));
                }
                parsed.chain = true;
            }
            "setvar" => {
                let raw_setvar = value.ok_or_else(|| {
                    compile_error(file, line, column, "setvar requires a value".to_string())
                })?;
                match parse_setvar(raw_setvar) {
                    Ok(setvar) => parsed.setvars.push(setvar),
                    Err(message) => {
                        if options.lenient {
                            tracing::warn!(file = %file.display(), line, "ignoring setvar: {message}");
                        } else {
                            return Err(compile_error(file, line, column, message));
                        }
                    }
                }
            }
            other => {
                if options.lenient {
                    tracing::warn!(file = %file.display(), line, "ignoring unknown action {other}");
                } else {
                    return Err(compile_error(
                        file,
                        line,
                        column,
                        format!("unknown action {other}"),
                    ));
                }
            }
        }
    }
    Ok(Some(parsed))
}

fn parse_setvar(raw: &str) -> Result<SetVar, String> {
    if let Some(target) = raw.strip_prefix('!') {
        let name = target
            .strip_prefix("tx.")
            .ok_or_else(|| "only tx. variables are supported by setvar".to_string())?;
        return Ok(SetVar {
            name: name.to_ascii_lowercase(),
            op: SetVarOp::Delete,
        });
    }
    let (target, value) = raw
        .split_once('=')
        .ok_or_else(|| "setvar requires name=value".to_string())?;
    let name = target
        .strip_prefix("tx.")
        .ok_or_else(|| "only tx. variables are supported by setvar".to_string())?
        .to_ascii_lowercase();
    let value = unquote(value);
    let op = if let Some(rest) = value.strip_prefix('+') {
        SetVarOp::Add(rest.to_string())
    } else if let Some(rest) = value.strip_prefix('-') {
        SetVarOp::Sub(rest.to_string())
    } else {
        SetVarOp::Assign(value)
    };
    Ok(SetVar { name, op })
}

fn split_actions(raw: &str) -> Vec<String> {
    let mut items = Vec::new();
    let mut current = String::new();
    let mut quote: Option<char> = None;
    let mut escaped = false;
    for ch in raw.chars() {
        if escaped {
            current.push(ch);
            escaped = false;
            continue;
        }
        if ch == '\\' && quote.is_some() {
            current.push(ch);
            escaped = true;
            continue;
        }
        if let Some(delimiter) = quote {
            current.push(ch);
            if ch == delimiter {
                quote = None;
            }
        } else if ch == '\'' || ch == '"' {
            current.push(ch);
            quote = Some(ch);
        } else if ch == ',' {
            let item = current.trim();
            if !item.is_empty() {
                items.push(item.to_string());
            }
            current.clear();
        } else {
            current.push(ch);
        }
    }
    let item = current.trim();
    if !item.is_empty() {
        items.push(item.to_string());
    }
    items
}

fn unquote(value: &str) -> String {
    let value = value.trim();
    let bytes = value.as_bytes();
    if bytes.len() >= 2 {
        let first = bytes[0];
        let last = bytes[bytes.len() - 1];
        if (first == b'\'' || first == b'"') && first == last {
            let delimiter = first as char;
            let inner = &value[1..value.len() - 1];
            let mut output = String::with_capacity(inner.len());
            let mut chars = inner.chars().peekable();
            while let Some(ch) = chars.next() {
                if ch == '\\' {
                    match chars.peek() {
                        Some(&next) if next == delimiter || next == '\\' => {
                            output.push(next);
                            chars.next();
                        }
                        _ => output.push('\\'),
                    }
                } else {
                    output.push(ch);
                }
            }
            return output;
        }
    }
    value.to_string()
}
```

```rust
use std::collections::BTreeMap;

#[derive(Debug, Default, Clone, PartialEq, Eq)]
pub struct TxStore {
    values: BTreeMap<String, String>,
}

impl TxStore {
    pub fn get(&self, name: &str) -> Option<&str> {
        self.values.get(&name.to_ascii_lowercase()).map(String::as_str)
    }

    pub fn set(&mut self, name: &str, value: String) {
        self.values.insert(name.to_ascii_lowercase(), value);
    }

    pub fn remove(&mut self, name: &str) -> Option<String> {
        self.values.remove(&name.to_ascii_lowercase())
    }

    pub fn iter(&self) -> impl Iterator<Item = (&str, &str)> {
        self.values
            .iter()
            .map(|(name, value)| (name.as_str(), value.as_str()))
    }

    pub fn values(&self) -> impl Iterator<Item = &str> {
        self.values.values().map(String::as_str)
    }
}

pub fn expand_macros(template: &str, tx: &TxStore) -> String {
    let mut output = String::with_capacity(template.len());
    let mut rest = template;
    while let Some(start) = rest.find("%{") {
        output.push_str(&rest[..start]);
        let after = &rest[start + 2..];
        if let Some(end) = after.find('}') {
            let name = after[..end].trim();
            if let Some(tx_name) = name.strip_prefix("tx.") {
                if let Some(value) = tx.get(tx_name) {
                    output.push_str(value);
                }
            }
            rest = &after[end + 1..];
        } else {
            output.push_str(&rest[start..]);
            return output;
        }
    }
    output.push_str(rest);
    output
}
```

```rust
use std::net::IpAddr;

use http::HeaderMap;

use crate::model::Variable;

use super::tx::TxStore;

#[derive(Debug, Clone, Copy)]
pub struct RequestView<'a> {
    pub method: &'a str,
    pub uri: &'a str,
    pub path: &'a str,
    pub query: Option<&'a str>,
    pub headers: &'a HeaderMap,
    pub body: &'a [u8],
    pub remote_addr: IpAddr,
}

#[derive(Debug, Clone)]
pub struct RequestContext {
    method: String,
    uri: String,
    path: String,
    query: Option<String>,
    headers: Vec<(String, String)>,
    query_pairs: Vec<(String, String)>,
    body_pairs: Vec<(String, String)>,
    cookies: Vec<(String, String)>,
    remote_addr: IpAddr,
    body: Vec<u8>,
    tx: TxStore,
}

impl RequestContext {
    pub fn new(view: &RequestView<'_>) -> Self {
        let headers: Vec<(String, String)> = view
            .headers
            .iter()
            .map(|(name, value)| {
                (
                    name.as_str().to_ascii_lowercase(),
                    String::from_utf8_lossy(value.as_bytes()).into_owned(),
                )
            })
            .collect();
        let query_pairs = view
            .query
            .map(|query| {
                form_urlencoded::parse(query.as_bytes())
                    .map(|(name, value)| (name.into_owned(), value.into_owned()))
                    .collect()
            })
            .unwrap_or_default();
        let cookies = headers
            .iter()
            .filter(|(name, _)| name == "cookie")
            .flat_map(|(_, value)| parse_cookies(value))
            .collect();

        Self {
            method: view.method.to_string(),
            uri: view.uri.to_string(),
            path: view.path.to_string(),
            query: view.query.map(str::to_string),
            headers,
            query_pairs,
            body_pairs: Vec::new(),
            cookies,
            remote_addr: view.remote_addr,
            body: Vec::new(),
            tx: TxStore::default(),
        }
    }

    pub fn set_body(&mut self, body: &[u8]) {
        self.body = body.to_vec();
        let is_form = self
            .headers
            .iter()
            .find(|(name, _)| name == "content-type")
            .map(|(_, value)| {
                value
                    .to_ascii_lowercase()
                    .starts_with("application/x-www-form-urlencoded")
            })
            .unwrap_or(false);
        self.body_pairs = if is_form {
            form_urlencoded::parse(body)
                .map(|(name, value)| (name.into_owned(), value.into_owned()))
                .collect()
        } else {
            Vec::new()
        };
    }

    pub fn tx(&self) -> &TxStore {
        &self.tx
    }

    pub fn tx_mut(&mut self) -> &mut TxStore {
        &mut self.tx
    }

    pub fn extract(&self, variable: &Variable) -> Vec<String> {
        match variable {
            Variable::RequestUri => vec![self.uri.clone()],
            Variable::RequestMethod => vec![self.method.clone()],
            Variable::QueryString => vec![self.query.clone().unwrap_or_default()],
            Variable::RequestFilename => vec![self.path.clone()],
            Variable::RequestHeaders(None) => {
                self.headers.iter().map(|(_, value)| value.clone()).collect()
            }
            Variable::RequestHeaders(Some(name)) => {
                let name = name.to_ascii_lowercase();
                self.headers
                    .iter()
                    .filter(|(header, _)| *header == name)
                    .map(|(_, value)| value.clone())
                    .collect()
            }
            Variable::Args => self
                .query_pairs
                .iter()
                .chain(self.body_pairs.iter())
                .map(|(_, value)| value.clone())
                .collect(),
            Variable::ArgsGet => self
                .query_pairs
                .iter()
                .map(|(_, value)| value.clone())
                .collect(),
            Variable::ArgsPost => self
                .body_pairs
                .iter()
                .map(|(_, value)| value.clone())
                .collect(),
            Variable::ArgsNames => self
                .query_pairs
                .iter()
                .chain(self.body_pairs.iter())
                .map(|(name, _)| name.clone())
                .collect(),
            Variable::RequestCookies(None) => {
                self.cookies.iter().map(|(_, value)| value.clone()).collect()
            }
            Variable::RequestCookies(Some(name)) => self
                .cookies
                .iter()
                .filter(|(cookie, _)| cookie.eq_ignore_ascii_case(name))
                .map(|(_, value)| value.clone())
                .collect(),
            Variable::RequestBody => {
                vec![String::from_utf8_lossy(&self.body).into_owned()]
            }
            Variable::RemoteAddr => vec![self.remote_addr.to_string()],
            Variable::Tx(None) => self.tx.values().map(str::to_string).collect(),
            Variable::Tx(Some(name)) => self
                .tx
                .get(name)
                .map(|value| vec![value.to_string()])
                .unwrap_or_default(),
        }
    }
}

fn parse_cookies(value: &str) -> Vec<(String, String)> {
    value
        .split(';')
        .filter_map(|item| {
            let item = item.trim();
            let (name, value) = item.split_once('=')?;
            Some((name.trim().to_string(), value.trim().to_string()))
        })
        .collect()
}
```

```rust
use std::collections::HashSet;
use std::time::{Duration, Instant};

use crate::error::EngineError;
use crate::model::{
    CompiledRule, CompiledRules, Disruptive, Phase, RuleGroup, SetVar, SetVarOp,
};
use crate::variables::request::{RequestContext, RequestView};
use crate::variables::tx::expand_macros;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Decision {
    Pass,
    Block {
        status: u16,
        rule_id: u32,
        msg: Option<String>,
    },
    Allow {
        rule_id: u32,
    },
}

impl Decision {
    pub fn is_decisive(&self) -> bool {
        !matches!(self, Self::Pass)
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RuleMatch {
    pub id: u32,
    pub msg: Option<String>,
    pub severity: Option<String>,
    pub tags: Vec<String>,
    pub logdata: Option<String>,
    pub log: bool,
}

#[derive(Debug, Clone)]
pub struct Evaluation {
    pub decision: Decision,
    pub matched: Vec<RuleMatch>,
    pub error: Option<EngineError>,
    pub latency: Duration,
}

#[derive(Debug, Clone)]
pub struct EvaluationState {
    context: RequestContext,
    decision: Decision,
    matched: Vec<RuleMatch>,
}

impl EvaluationState {
    pub fn new(view: &RequestView<'_>) -> Self {
        Self {
            context: RequestContext::new(view),
            decision: Decision::Pass,
            matched: Vec::new(),
        }
    }

    pub fn set_body(&mut self, body: &[u8]) {
        self.context.set_body(body);
    }

    pub fn decision(&self) -> &Decision {
        &self.decision
    }

    pub fn matched(&self) -> &[RuleMatch] {
        &self.matched
    }

    pub fn evaluate_phase(&mut self, rules: &CompiledRules, phase: Phase) {
        if self.decision.is_decisive() {
            return;
        }
        let groups = match phase {
            Phase::Phase1 => &rules.phase1,
            Phase::Phase2 => &rules.phase2,
        };
        for group in groups {
            if self.decision.is_decisive() {
                break;
            }
            match group {
                RuleGroup::Single(rule) => {
                    if self.rule_matches(rule) {
                        self.apply_actions(rule);
                    }
                }
                RuleGroup::Chain(chain) => {
                    for rule in chain {
                        if !self.rule_matches(rule) {
                            break;
                        }
                        self.apply_actions(rule);
                        if self.decision.is_decisive() {
                            break;
                        }
                    }
                }
            }
        }
    }

    pub fn finish(self, started: Instant) -> Evaluation {
        Evaluation {
            decision: self.decision,
            matched: self.matched,
            error: None,
            latency: started.elapsed(),
        }
    }

    fn rule_matches(&self, rule: &CompiledRule) -> bool {
        if rule.unconditional {
            return true;
        }
        let excluded: HashSet<String> = rule
            .variables
            .iter()
            .filter(|spec| spec.negated)
            .flat_map(|spec| self.context.extract(&spec.variable))
            .collect();
        let values: Vec<String> = rule
            .variables
            .iter()
            .filter(|spec| !spec.negated)
            .flat_map(|spec| self.context.extract(&spec.variable))
            .filter(|value| !excluded.contains(value))
            .collect();
        if values.is_empty() {
            return false;
        }
        values.iter().any(|value| {
            let transformed = rule
                .transformations
                .iter()
                .fold(std::borrow::Cow::Borrowed(value.as_str()), |current, transform| {
                    transform.apply(&current).into_owned().into()
                });
            let matched = rule.operator.matches(&transformed);
            if rule.operator_negated {
                !matched
            } else {
                matched
            }
        })
    }

    fn apply_actions(&mut self, rule: &CompiledRule) {
        for setvar in &rule.actions.setvars {
            self.apply_setvar(setvar);
        }
        let msg = rule
            .actions
            .msg
            .as_ref()
            .map(|template| expand_macros(template, self.context.tx()));
        let logdata = rule
            .actions
            .logdata
            .as_ref()
            .map(|template| expand_macros(template, self.context.tx()));
        self.matched.push(RuleMatch {
            id: rule.id,
            msg: msg.clone(),
            severity: rule.actions.severity.clone(),
            tags: rule.actions.tags.clone(),
            logdata,
            log: rule.actions.log,
        });
        match &rule.actions.disruptive {
            Some(Disruptive::Deny { status }) => {
                self.decision = Decision::Block {
                    status: *status,
                    rule_id: rule.id,
                    msg,
                };
            }
            Some(Disruptive::Allow) => {
                self.decision = Decision::Allow { rule_id: rule.id };
            }
            None => {}
        }
    }

    fn apply_setvar(&mut self, setvar: &SetVar) {
        match &setvar.op {
            SetVarOp::Assign(template) => {
                let value = expand_macros(template, self.context.tx());
                self.context.tx_mut().set(&setvar.name, value);
            }
            SetVarOp::Add(template) => {
                let delta = macro_integer(template, &self.context);
                let current = self
                    .context
                    .tx()
                    .get(&setvar.name)
                    .and_then(|value| value.parse::<i64>().ok())
                    .unwrap_or(0);
                self.context
                    .tx_mut()
                    .set(&setvar.name, (current + delta).to_string());
            }
            SetVarOp::Sub(template) => {
                let delta = macro_integer(template, &self.context);
                let current = self
                    .context
                    .tx()
                    .get(&setvar.name)
                    .and_then(|value| value.parse::<i64>().ok())
                    .unwrap_or(0);
                self.context
                    .tx_mut()
                    .set(&setvar.name, (current - delta).to_string());
            }
            SetVarOp::Delete => {
                self.context.tx_mut().remove(&setvar.name);
            }
        }
    }
}

fn macro_integer(template: &str, context: &RequestContext) -> i64 {
    expand_macros(template, context.tx())
        .trim()
        .parse::<i64>()
        .unwrap_or(0)
}

pub fn evaluate_phase(state: &mut EvaluationState, rules: &CompiledRules, phase: Phase) {
    state.evaluate_phase(rules, phase);
}

pub fn evaluate(rules: &CompiledRules, view: &RequestView<'_>) -> Evaluation {
    let started = Instant::now();
    let mut state = EvaluationState::new(view);
    state.evaluate_phase(rules, Phase::Phase1);
    if !state.decision().is_decisive() {
        state.set_body(view.body);
        state.evaluate_phase(rules, Phase::Phase2);
    }
    state.finish(started)
}
```

One performance note: the fold calls `into_owned()` after each transform, allocating even for borrowed values. Prefer:

```rust
let transformed = rule.transformations.iter().fold(
    std::borrow::Cow::Borrowed(value.as_str()),
    |current, transform| transform.apply(&current),
);
```

Use this simpler version in the implementation; `transform.apply(&current)` returns `Cow<'_, str>` borrowed from `current`, which works because `current` lives through the closure call? The closure returns a Cow borrowing from the input `current`, then next iteration borrows from that returned Cow. This is a known pattern and compiles with `Cow`, because the fold's accumulator owns the Cow and each step returns a Cow tied to the accumulator's lifetime via the closure parameter. If the borrow checker complains, the `into_owned()` version is the safe fallback. Start with the simple fold.

```rust
async fn handle(
    request: Request<Incoming>,
    state: Arc<AppState>,
    peer: SocketAddr,
) -> Result<Response<ProxyBody>, Infallible> {
    let (parts, incoming) = request.into_parts();
    let rules = state.rules.snapshot();

    let uri_len = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str().len())
        .unwrap_or(0);
    if uri_len > state.config.limits.max_uri_bytes {
        return Ok(text_response(StatusCode::URI_TOO_LONG, "URI too long\n"));
    }
    if header_bytes(&parts.headers) > state.config.limits.max_header_bytes {
        return Ok(text_response(
            StatusCode::REQUEST_HEADER_FIELDS_TOO_LARGE,
            "request headers too large\n",
        ));
    }

    let uri_string = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str())
        .unwrap_or("/")
        .to_string();
    let view = RequestView {
        method: parts.method.as_str(),
        uri: &uri_string,
        path: parts.uri.path(),
        query: parts.uri.query(),
        headers: &parts.headers,
        body: &[],
        remote_addr: peer.ip(),
    };
    let mut evaluation = EvaluationState::new(&view);
    evaluate_phase(&mut evaluation, &rules, Phase::Phase1);

    let skip_phase_two = matches!(evaluation.decision(), Decision::Allow { .. });
    if let Decision::Block { status, .. } = evaluation.decision() {
        return Ok(text_response(
            StatusCode::from_u16(*status).unwrap_or(StatusCode::FORBIDDEN),
            "request blocked\n",
        ));
    }

    if let Some(length) = content_length(&parts.headers) {
        if length > state.config.limits.max_body_bytes as u64 {
            return Ok(text_response(
                StatusCode::PAYLOAD_TOO_LARGE,
                "request body too large\n",
            ));
        }
    }

    let body = match limits::read_body_limited(
        incoming,
        state.config.limits.max_body_bytes,
        Duration::from_millis(state.config.limits.body_read_timeout_ms),
    )
    .await
    {
        Ok(body) => body,
        Err(limits::BodyError::TooLarge) => {
            return Ok(text_response(
                StatusCode::PAYLOAD_TOO_LARGE,
                "request body too large\n",
            ));
        }
        Err(limits::BodyError::Timeout) => {
            return Ok(text_response(
                StatusCode::REQUEST_TIMEOUT,
                "request body read timeout\n",
            ));
        }
        Err(limits::BodyError::Hyper(error)) => {
            warn!(%peer, %error, "failed to read request body");
            return Ok(text_response(
                StatusCode::BAD_REQUEST,
                "invalid request body\n",
            ));
        }
    };

    if !skip_phase_two {
        evaluation.set_body(&body);
        evaluate_phase(&mut evaluation, &rules, Phase::Phase2);
        if let Decision::Block { status, .. } = evaluation.decision() {
            return Ok(text_response(
                StatusCode::from_u16(*status).unwrap_or(StatusCode::FORBIDDEN),
                "request blocked\n",
            ));
        }
    }

    match forward::forward(&state, &parts, body, peer.ip()).await {
        Ok(response) => Ok(response),
        Err(forward::ForwardError::Timeout) => Ok(text_response(
            StatusCode::GATEWAY_TIMEOUT,
            "upstream timeout\n",
        )),
        Err(forward::ForwardError::Upstream(error)) => {
            warn!(%peer, %error, "upstream request failed");
            Ok(text_response(StatusCode::BAD_GATEWAY, "upstream error\n"))
        }
    }
}
```

Note: `EvaluationState::decision()` returns `&Decision`; matching with `Decision::Block { status, .. }` binds `status: &u16`. Use `*status`. The code above does this.

```rust
use std::path::PathBuf;
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::Arc;

use aegis_engine::audit::{AuditEvent, MatchedRule, UpstreamInfo};
use aegis_engine::{Decision, RuleMatch};
use tokio::io::{AsyncWriteExt, BufWriter};
use tokio::sync::mpsc;

use crate::config::{AuditConfig, AuditMode, AuditSink};

#[derive(Clone)]
pub struct AuditHandle {
    tx: mpsc::Sender<AuditEvent>,
    dropped: Arc<AtomicU64>,
}

impl AuditHandle {
    pub fn channel(capacity: usize) -> (Self, mpsc::Receiver<AuditEvent>) {
        let (tx, rx) = mpsc::channel(capacity.max(1));
        (
            Self {
                tx,
                dropped: Arc::new(AtomicU64::new(0)),
            },
            rx,
        )
    }

    pub fn try_send(&self, event: AuditEvent) {
        if self.tx.try_send(event).is_err() {
            self.dropped.fetch_add(1, Ordering::Relaxed);
        }
    }

    pub fn dropped(&self) -> u64 {
        self.dropped.load(Ordering::Relaxed)
    }
}

pub fn should_write(
    mode: AuditMode,
    decision: &Decision,
    matched: &[RuleMatch],
    status: u16,
    upstream_status: Option<u16>,
    error: Option<&str>,
) -> bool {
    match mode {
        AuditMode::All => true,
        AuditMode::BlockedOnly => {
            decision.is_decisive()
                || error.is_some()
                || (status >= 400 && upstream_status.is_none())
                || matched.iter().any(|rule| rule.log)
        }
    }
}

pub struct EventInput<'a> {
    pub request_id: &'a str,
    pub client_ip: std::net::IpAddr,
    pub method: &'a str,
    pub path: &'a str,
    pub query: Option<&'a str>,
    pub decision: &'a Decision,
    pub matched: &'a [RuleMatch],
    pub status: u16,
    pub upstream_status: Option<u16>,
    pub upstream_latency_ms: Option<u64>,
    pub error: Option<String>,
    pub latency_ms: u64,
    pub request_bytes: u64,
    pub rules_version: u64,
    pub include_query: bool,
    pub matched_limit: usize,
}

pub fn build_event(input: EventInput<'_>) -> AuditEvent {
    let decision_label = match input.decision {
        Decision::Pass if input.error.is_some() => "error",
        Decision::Pass if input.status >= 400 && input.upstream_status.is_none() => "block",
        Decision::Pass => "pass",
        Decision::Block { .. } => "block",
        Decision::Allow { .. } => "allow",
    };
    let rule_id = match input.decision {
        Decision::Pass => None,
        Decision::Block { rule_id, .. } => Some(*rule_id),
        Decision::Allow { rule_id } => Some(*rule_id),
    };
    let rule_msg = match input.decision {
        Decision::Block { msg, .. } => msg.clone(),
        _ => None,
    };
    let decision_rule = rule_id.and_then(|id| input.matched.iter().find(|rule| rule.id == id));
    let rule_data = decision_rule.and_then(|rule| rule.logdata.clone());
    let severity = decision_rule.and_then(|rule| rule.severity.clone());
    let tags = decision_rule
        .map(|rule| rule.tags.clone())
        .unwrap_or_default();
    let matched_rules: Vec<MatchedRule> = input
        .matched
        .iter()
        .take(input.matched_limit)
        .map(|rule| MatchedRule {
            id: rule.id,
            msg: rule.msg.clone(),
            severity: rule.severity.clone(),
            tags: rule.tags.clone(),
        })
        .collect();

    AuditEvent {
        event_version: 1,
        ts: chrono::Utc::now().to_rfc3339_opts(chrono::SecondsFormat::Millis, true),
        request_id: input.request_id.to_string(),
        client_ip: input.client_ip.to_string(),
        method: input.method.to_string(),
        path: input.path.to_string(),
        query: if input.include_query {
            input.query.map(str::to_string)
        } else {
            None
        },
        decision: decision_label.to_string(),
        status: input.status,
        rule_id,
        rule_msg,
        rule_data,
        severity,
        tags,
        matched_rules,
        error: input.error,
        upstream: UpstreamInfo {
            status: input.upstream_status,
            latency_ms: input.upstream_latency_ms,
        },
        latency_ms: input.latency_ms,
        request_bytes: input.request_bytes,
        rules_version: input.rules_version,
    }
}

pub async fn run(config: AuditConfig, mut receiver: mpsc::Receiver<AuditEvent>) {
    match config.sink {
        AuditSink::None => {
            while receiver.recv().await.is_some() {}
        }
        AuditSink::Stdout => {
            while let Some(event) = receiver.recv().await {
                match serde_json::to_string(&event) {
                    Ok(line) => println!("{line}"),
                    Err(error) => tracing::error!(%error, "failed to serialize audit event"),
                }
            }
        }
        AuditSink::File => {
            let path = match config.path.as_deref() {
                Some(path) => PathBuf::from(path),
                None => {
                    tracing::error!("audit.path missing; audit disabled");
                    while receiver.recv().await.is_some() {}
                    return;
                }
            };
            if let Some(parent) = path.parent() {
                if !parent.as_os_str().is_empty() {
                    if let Err(error) = tokio::fs::create_dir_all(parent).await {
                        tracing::error!(%error, "failed to create audit directory");
                    }
                }
            }
            match tokio::fs::OpenOptions::new()
                .create(true)
                .append(true)
                .open(&path)
                .await
            {
                Ok(file) => {
                    let mut writer = BufWriter::new(file);
                    while let Some(event) = receiver.recv().await {
                        match serde_json::to_vec(&event) {
                            Ok(mut line) => {
                                line.push(b'\n');
                                if writer.write_all(&line).await.is_err()
                                    || writer.flush().await.is_err()
                                {
                                    tracing::error!("failed to write audit event");
                                }
                            }
                            Err(error) => {
                                tracing::error!(%error, "failed to serialize audit event")
                            }
                        }
                    }
                }
                Err(error) => {
                    tracing::error!(%error, "failed to open audit file");
                    while receiver.recv().await.is_some() {}
                }
            }
        }
    }
}
```

```rust
fn estimate_request_bytes(parts: &http::request::Parts) -> u64 {
    let headers: usize = parts
        .headers
        .iter()
        .map(|(name, value)| name.as_str().len() + value.as_bytes().len() + 4)
        .sum();
    (parts.method.as_str().len() + parts.uri.to_string().len() + 12 + headers) as u64
}

async fn process(
    state: &AppState,
    rules: &aegis_engine::CompiledRules,
    parts: &http::request::Parts,
    incoming: Incoming,
    peer: SocketAddr,
    evaluation: &mut EvaluationState,
) -> Outcome {
    let uri_len = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str().len())
        .unwrap_or(0);
    if uri_len > state.config.limits.max_uri_bytes {
        return local(StatusCode::URI_TOO_LONG, "URI too long\n");
    }
    if header_bytes(&parts.headers) > state.config.limits.max_header_bytes {
        return local(
            StatusCode::REQUEST_HEADER_FIELDS_TOO_LARGE,
            "request headers too large\n",
        );
    }

    evaluate_phase(evaluation, rules, Phase::Phase1);
    if let Decision::Block { status, .. } = evaluation.decision() {
        return blocked(*status, 0);
    }
    let skip_phase_two = matches!(evaluation.decision(), Decision::Allow { .. });

    if let Some(length) = content_length(&parts.headers) {
        if length > state.config.limits.max_body_bytes as u64 {
            return local(StatusCode::PAYLOAD_TOO_LARGE, "request body too large\n");
        }
    }

    let body = match limits::read_body_limited(
        incoming,
        state.config.limits.max_body_bytes,
        Duration::from_millis(state.config.limits.body_read_timeout_ms),
    )
    .await
    {
        Ok(body) => body,
        Err(limits::BodyError::TooLarge) => {
            return local(StatusCode::PAYLOAD_TOO_LARGE, "request body too large\n");
        }
        Err(limits::BodyError::Timeout) => {
            return local(StatusCode::REQUEST_TIMEOUT, "request body read timeout\n");
        }
        Err(limits::BodyError::Hyper(error)) => {
            warn!(%peer, %error, "failed to read request body");
            return local(StatusCode::BAD_REQUEST, "invalid request body\n");
        }
    };
    let body_len = body.len();

    if !skip_phase_two {
        evaluation.set_body(&body);
        evaluate_phase(evaluation, rules, Phase::Phase2);
        if let Decision::Block { status, .. } = evaluation.decision() {
            return blocked(*status, body_len);
        }
    }

    let upstream_started = Instant::now();
    match forward::forward(state, parts, body, peer.ip()).await {
        Ok(response) => {
            let status = response.status();
            Outcome {
                response,
                status,
                upstream_status: Some(status.as_u16()),
                upstream_latency_ms: Some(upstream_started.elapsed().as_millis() as u64),
                error: None,
                request_body_bytes: body_len,
            }
        }
        Err(forward::ForwardError::Timeout) => Outcome {
            response: text_response(StatusCode::GATEWAY_TIMEOUT, "upstream timeout\n"),
            status: StatusCode::GATEWAY_TIMEOUT,
            upstream_status: None,
            upstream_latency_ms: Some(upstream_started.elapsed().as_millis() as u64),
            error: Some("upstream_timeout".to_string()),
            request_body_bytes: body_len,
        },
        Err(forward::ForwardError::Upstream(message)) => {
            warn!(%peer, %message, "upstream request failed");
            Outcome {
                response: text_response(StatusCode::BAD_GATEWAY, "upstream error\n"),
                status: StatusCode::BAD_GATEWAY,
                upstream_status: None,
                upstream_latency_ms: Some(upstream_started.elapsed().as_millis() as u64),
                error: Some(format!("upstream_error: {message}")),
                request_body_bytes: body_len,
            }
        }
    }
}

fn emit_audit(
    state: &AppState,
    request_id: &str,
    peer: SocketAddr,
    started: Instant,
    method: &str,
    path: &str,
    query: Option<&str>,
    request_bytes: u64,
    rules_version: u64,
    evaluation: &Evaluation,
    outcome: &Outcome,
) {
    if !audit_sink::should_write(
        state.config.audit.mode,
        &evaluation.decision,
        &evaluation.matched,
        outcome.status.as_u16(),
        outcome.upstream_status,
        outcome.error.as_deref(),
    ) {
        return;
    }
    let event = audit_sink::build_event(audit_sink::EventInput {
        request_id,
        client_ip: peer.ip(),
        method,
        path,
        query,
        decision: &evaluation.decision,
        matched: &evaluation.matched,
        status: outcome.status.as_u16(),
        upstream_status: outcome.upstream_status,
        upstream_latency_ms: outcome.upstream_latency_ms,
        error: outcome.error.clone(),
        latency_ms: started.elapsed().as_millis() as u64,
        request_bytes,
        rules_version,
        include_query: state.config.audit.include_query,
        matched_limit: state.config.audit.matched_rules_limit,
    });
    state.audit.try_send(event);
}

async fn handle(
    request: Request<Incoming>,
    state: Arc<AppState>,
    peer: SocketAddr,
) -> Result<Response<ProxyBody>, Infallible> {
    let started = Instant::now();
    let request_id = Uuid::new_v4().to_string();
    let (parts, incoming) = request.into_parts();
    let method = parts.method.as_str().to_string();
    let path = parts.uri.path().to_string();
    let query = parts.uri.query().map(str::to_string);
    let uri_string = parts
        .uri
        .path_and_query()
        .map(|value| value.as_str())
        .unwrap_or("/")
        .to_string();
    let rules = state.rules.snapshot();
    let rules_version = rules.version;

    let mut evaluation = {
        let view = RequestView {
            method: &method,
            uri: &uri_string,
            path: &path,
            query: query.as_deref(),
            headers: &parts.headers,
            body: &[],
            remote_addr: peer.ip(),
        };
        EvaluationState::new(&view)
    };

    let outcome = process(&state, &rules, &parts, incoming, peer, &mut evaluation).await;
    let request_bytes = estimate_request_bytes(&parts) + outcome.request_body_bytes as u64;
    let evaluation = evaluation.finish(started);
    emit_audit(
        &state,
        &request_id,
        peer,
        started,
        &method,
        &path,
        query.as_deref(),
        request_bytes,
        rules_version,
        &evaluation,
        &outcome,
    );
    Ok(outcome.response)
}
```

```rust
use std::path::PathBuf;
use std::sync::{Arc, Mutex as StdMutex};

use aegis_engine::{CompiledRules, LoadError, LoadOptions, load_rules};
use arc_swap::ArcSwap;
use thiserror::Error;
use tokio::sync::Mutex;

#[derive(Debug, Error)]
pub enum ReloadError {
    #[error(transparent)]
    Load(#[from] LoadError),
    #[error("reload task failed: {0}")]
    Task(String),
}

pub struct RulesManager {
    files: Vec<PathBuf>,
    lenient: bool,
    current: ArcSwap<CompiledRules>,
    reload_lock: Mutex<()>,
    loaded_at: StdMutex<String>,
}

impl RulesManager {
    pub fn load_initial(files: &[PathBuf], lenient: bool) -> Result<Self, LoadError> {
        let rules = load_rules(
            files,
            &LoadOptions {
                lenient,
                version: 1,
            },
        )?;
        Ok(Self {
            files: files.to_vec(),
            lenient,
            current: ArcSwap::from_pointee(rules),
            reload_lock: Mutex::new(()),
            loaded_at: StdMutex::new(now_rfc3339()),
        })
    }

    pub fn snapshot(&self) -> Arc<CompiledRules> {
        self.current.load_full()
    }

    pub fn files(&self) -> &[PathBuf] {
        &self.files
    }

    pub fn loaded_at(&self) -> String {
        self.loaded_at
            .lock()
            .map(|value| value.clone())
            .unwrap_or_default()
    }

    pub async fn reload(&self) -> Result<Arc<CompiledRules>, ReloadError> {
        let _guard = self.reload_lock.lock().await;
        let files = self.files.clone();
        let lenient = self.lenient;
        let version = self.current.load().version + 1;
        let loaded = tokio::task::spawn_blocking(move || {
            load_rules(
                &files,
                &LoadOptions {
                    lenient,
                    version,
                },
            )
        })
        .await
        .map_err(|error| ReloadError::Task(error.to_string()))??;
        let loaded = Arc::new(loaded);
        self.current.store(loaded.clone());
        if let Ok(mut value) = self.loaded_at.lock() {
            *value = now_rfc3339();
        }
        Ok(loaded)
    }
}

fn now_rfc3339() -> String {
    chrono::Utc::now().to_rfc3339_opts(chrono::SecondsFormat::Millis, true)
}
```

Note: `reload` returns `Result<Arc<CompiledRules>, ReloadError>`; the `??` unwraps `JoinError` (mapped) then `LoadError` (via `From`). Write it explicitly if the compiler struggles:

```rust
    load_rules(&files, &LoadOptions { lenient, version })
})

.map_err(ReloadError::Load)?;
```

```rust
use std::convert::Infallible;
use std::sync::Arc;

use bytes::Bytes;
use hyper::body::Incoming;
use hyper::header::{AUTHORIZATION, CONTENT_TYPE};
use hyper::service::service_fn;
use hyper::{Method, Request, Response, StatusCode};
use hyper_util::rt::TokioIo;
use serde_json::json;
use tokio::net::TcpListener;

use crate::proxy::{ProxyBody, full_body};
use crate::state::AppState;

pub async fn serve_on(listener: TcpListener, state: Arc<AppState>) -> anyhow::Result<()> {
    loop {
        let (stream, peer) = listener.accept().await?;
        let state = state.clone();
        tokio::spawn(async move {
            let io = TokioIo::new(stream);
            let service = service_fn(move |request| handle(request, state.clone()));
            if let Err(error) = hyper::server::conn::http1::Builder::new()
                .serve_connection(io, service)
                .await
            {
                tracing::debug!(%peer, %error, "admin connection closed");
            }
        });
    }
}

async fn handle(
    request: Request<Incoming>,
    state: Arc<AppState>,
) -> Result<Response<ProxyBody>, Infallible> {
    if !authorized(&request, &state) {
        return Ok(json_response(
            StatusCode::UNAUTHORIZED,
            json!({"error": "unauthorized"}),
        ));
    }
    match (request.method(), request.uri().path()) {
        (&Method::GET, "/healthz") => {
            Ok(json_response(StatusCode::OK, json!({"status": "ok"})))
        }
        (&Method::GET, "/readyz") => {
            Ok(json_response(StatusCode::OK, json!({"status": "ready"})))
        }
        (&Method::GET, "/status") => {
            let rules = state.rules.snapshot();
            Ok(json_response(
                StatusCode::OK,
                json!({
                    "version": env!("CARGO_PKG_VERSION"),
                    "uptime_seconds": state.started_at.elapsed().as_secs(),
                    "rules": {
                        "version": rules.version,
                        "count": rules.rule_count,
                        "files": state.rules.files().iter().map(|path| path.display().to_string()).collect::<Vec<_>>(),
                        "loaded_at": state.rules.loaded_at(),
                    },
                    "audit": {"dropped": state.audit.dropped()},
                    "ready": true,
                }),
            ))
        }
        (&Method::GET, "/rules") => {
            let rules = state.rules.snapshot();
            Ok(json_response(
                StatusCode::OK,
                json!({
                    "version": rules.version,
                    "count": rules.rule_count,
                    "files": state.rules.files().iter().map(|path| path.display().to_string()).collect::<Vec<_>>(),
                    "loaded_at": state.rules.loaded_at(),
                }),
            ))
        }
        (&Method::POST, "/rules/reload") => match state.rules.reload().await {
            Ok(rules) => Ok(json_response(
                StatusCode::OK,
                json!({
                    "rules_version": rules.version,
                    "count": rules.rule_count,
                    "loaded_at": state.rules.loaded_at(),
                }),
            )),
            Err(error) => Ok(json_response(
                StatusCode::BAD_REQUEST,
                json!({"error": error.to_string()}),
            )),
        },
        _ => Ok(json_response(
            StatusCode::NOT_FOUND,
            json!({"error": "not found"}),
        )),
    }
}

fn authorized(request: &Request<Incoming>, state: &AppState) -> bool {
    match state.config.admin.token.as_deref() {
        None => true,
        Some(token) => request
            .headers()
            .get(AUTHORIZATION)
            .and_then(|value| value.to_str().ok())
            .map(|value| value == format!("Bearer {token}"))
            .unwrap_or(false),
    }
}

fn json_response(status: StatusCode, value: serde_json::Value) -> Response<ProxyBody> {
```

```rust
pub async fn shutdown_signal() {

pub async fn sighup_loop(state: Arc<AppState>) {
    use tokio::signal::unix::{SignalKind, signal};

        tracing::error!("failed to install SIGHUP handler");
        return;
```

```rust
pub async fn serve_on_with_shutdown(
    listener: TcpListener,
    state: Arc<AppState>,
    mut shutdown: tokio::sync::watch::Receiver<bool>,
) -> anyhow::Result<()> {
    let mut connections = tokio::task::JoinSet::new();
    loop {
        tokio::select! {
            changed = shutdown.changed() => {
                if changed.is_err() || *shutdown.borrow() {
                    break;
                }
            }
            accepted = listener.accept() => {
                let (stream, peer) = accepted?;
                let header_timeout =
                    Duration::from_millis(state.config.limits.header_read_timeout_ms);
                let state = state.clone();
                connections.spawn(async move {
                    let io = TokioIo::new(stream);
                    let service = service_fn(move |request| handle(request, state.clone(), peer));
                    let mut builder = hyper::server::conn::http1::Builder::new();
                    builder.timer(TokioTimer::new());
                    builder.header_read_timeout(header_timeout);
                    if let Err(error) = builder.serve_connection(io, service).await {
                        debug!(%peer, %error, "connection closed");
                    }
                });
            }
        }
    }
    let drain = async {
        while connections.join_next().await.is_some() {}
    };
    let _ = tokio::time::timeout(Duration::from_secs(10), drain).await;
    connections.abort_all();
    Ok(())
}
```

## Implementation Notes (M0-M1 executed)

Tasks 1-8 were implemented on branch `m0-m1`. The code differs from the task snippets in these verified ways:

- `block` is not a `deny` synonym. It is a placeholder for the disruptive action defined by `SecDefaultAction`; without a default action it falls back to `deny` 403. `block` is rejected inside `SecDefaultAction`. See `compile.rs::resolve_disruptive`.
- `SecAction` now inherits `SecDefaultAction` for `phase`, disruptive action, `status`, and `log`.
- Explicit `pass` prevents a rule from inheriting a default `deny`.
- Non-disruptive chain actions (`setvar`, metadata) execute when each chain link matches and are not rolled back if a later link fails. This matches ModSecurity's documented `setvar` behavior; disruptive actions remain restricted to the chain tail.
- Rule file order: explicit `rules.files` entries keep configuration order; each glob is sorted internally; duplicates keep the first occurrence.
- Header read timeout uses hyper's `header_read_timeout`, which closes the connection rather than returning 408. Request-body read timeouts return 408.
- `crates/aegis-engine/src/compile.rs` contains the additional `resolve_disruptive` helper; the Task 5 snippet does not show it.

Tasks 9-14 remain unchanged.
